隱私政策

最後更新：2026 年 5 月 26 日

Knownli（以下簡稱「本服務」）由謙謙影像工作室所營運，致力於保護您的個人隱私。本政策說明我們如何收集、使用與保護您的個人資料。

一、資料收集範圍

使用本服務時，我們可能收集以下資料：

  • 店家資訊：店名、聯絡人姓名、電話、LINE 帳號
  • 客人訂位資訊：姓名、電話末四碼、訂位時間與人數、口味偏好與備註
  • 系統使用紀錄：登入時間、操作記錄、裝置資訊

二、資料使用目的

收集的資料僅用於以下目的：

  • 提供訂位管理、顧客關係管理（CRM）核心功能
  • 發送 LINE 訂位確認、提醒與通知訊息
  • 改善系統穩定性與使用體驗
  • 客服與技術支援

三、資料儲存與安全

所有資料儲存於 Supabase 雲端資料庫，採用 AES-256 加密與行級安全（Row Level Security）保護。我們不會將您的個人資料出售、租借或交換給任何第三方。

四、LINE 整合

本服務透過 LINE Messaging API 提供訂位通知功能。當客人使用 LINE 訂位時，系統僅取得 LINE 顯示名稱及 User ID，不會存取其他 LINE 帳號資訊。相關資料處理遵循 LINE 服務條款。

五、資料保留期限

訂位與顧客資料依店家需求保留，店家可隨時於後台刪除個別顧客資料。帳號停用後，系統資料將於 90 天內完整刪除。

六、您的權利

依據個人資料保護法，您有權要求查詢、更正或刪除個人資料。如需行使上述權利，請透過以下方式聯絡我們。
