📋 LINE 設定教學

依照以下步驟提供 Knownli 訂位系統需要的 LINE 資料，大約 10 分鐘完成。

方案一：自己找資料 方案二：邀請協作
🔑 方案一：自己找資料傳給我

你需要到兩個不同的 LINE 後台各找一個資料，加起來大約 10 分鐘。
找到後直接用 LINE 傳給我就好。

ℹ️ 這份教學是以「Knownli」帳號示範，你的畫面會顯示自己的帳號名稱，步驟完全相同。
第一部分：到 LINE Developers 找兩個金鑰
1
登入 LINE Developers Console

打開瀏覽器前往 developers.line.biz/console， 用 LINE 帳號登入後就會看到這個畫面。

✦ 左側「Providers」欄位會列出你的帳號，點選對應的帳號名稱。
2
進入你的 Messaging API Channel

點選帶有 Messaging API 標籤的那個 Channel，進去後會看到下方的分頁列。

✦ 紅框是你接下來要用的兩個分頁：Basic settings（找 Channel Secret）和 Messaging API（找 Access Token）。
3
在 Basic settings 找到 Channel secret

停在 Basic settings 分頁，往下捲動，找到 Channel secret 那一行，把右側的值複製起來。

✦ 紅框那一行就是 Channel secret，點右側的複製圖示即可。
⚠️ Channel secret 是你帳號的私密金鑰，請直接用 LINE 私訊傳給我，不要貼在公開地方。
4
在 Messaging API 找到 Channel access token

點上方的 Messaging API 分頁，一路往下捲到底，找到 Channel access token (long-lived) 區塊。
如果框框是空的，點 Issue 按鈕產生一組；已有內容就直接複製。

✦ 紅框內的長串文字就是 Channel access token，點右側複製圖示。
✅ 找到這兩樣東西後，LINE 私訊傳給我就完成了！
要傳的：① Channel secret  ② Channel access token
第二部分
第二部分：到 LINE Official Account Manager 找老闆 LINE ID
ℹ️ 這個 ID 是讓系統在有新訂位時自動通知你，只需要做一次。
5
登入 LINE Official Account Manager

前往 manager.line.biz， 登入後可以看到你管理的帳號列表。點選你的帳號進去。

✦ 點選帳號名稱進入管理介面。
6
取得你的 LINE User ID

最快的方法：用你自己的手機 LINE，傳一則訊息給這個 LINE OA 帳號。
傳完後，我從後台 Webhook 記錄裡撈出你的 User ID（你不需要做任何設定）。

📱 步驟：打開 LINE → 搜尋你的 OA 帳號 → 傳任何一則訊息給它（例如「測試」）→ 告訴我你傳了 → 我去撈 ID。
✅ 需要傳給我的資料清單
① Channel secret（從 LINE Developers → Basic settings）
② Channel access token（從 LINE Developers → Messaging API）
③ 傳一則訊息給你的 LINE OA（讓我抓你的 User ID）
🤝 方案二：邀請我當管理員

你只需要在兩個後台各做一次邀請，之後我自己進去完成所有設定，
你完全不需要找任何技術資料。

🛡️ 管理員權限讓我可以幫你設定，但不能刪帳號、修改付款或管理成員，隨時可以移除我的權限。
第一步：在 LINE Official Account Manager 邀請我
1
進入你的 LINE OA 帳號

前往 manager.line.biz， 登入後點選你的帳號名稱。

✦ 點選紅框裡的帳號名稱。
2
進入「設定 → 權限管理」

進入帳號後，點右上角的 設定，再從左側選單選 權限管理。

✦ 右上角「設定」→ 左側「權限管理」，兩個地方各有紅框標示。
3
點「新增管理成員」

在「權限管理」頁面，點右側的 新增管理成員 綠色按鈕。

✦ 右側的綠色按鈕。
4
選「管理員」→ 發行連結傳給我

跳出視窗後：
① 把「權限種類」下拉選單改成 管理員
② 點 發行網址 產生邀請連結
③ 把連結用 LINE 傳給我

✦ 上方紅框改選「管理員」，下方紅框點「發行網址」。連結 24 小時內有效，傳給我就好。
⚠️ 預設是「操作人員」，記得改成「管理員」才能讓我設定 API 金鑰。
